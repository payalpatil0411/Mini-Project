# E-Tech - E-Waste Management System

## About the Project
E-Tech is a mini-project developed to spread awareness about electronic waste management. It provides information about e-waste and encourages people to dispose of electronic items responsibly.

## Objectives
- To create awareness about electronic waste.
- To provide information about e-waste management.
- To encourage responsible recycling and disposal of electronic items.
- To create a simple and user-friendly website.

## Technologies Used
- HTML
- CSS (if used in the current project)

## Project Pages
- Home (`index.html`): Introduction to the E-Tech project.
- About (`about.html`): Information about the project.
- Login (`login.html`): Login page interface.
- Register (`register.html`): Registration page interface.

## Future Scope
- Add user registration and login functionality.
- Add e-waste collection and pickup requests.
- Connect the website to a database.
- Provide information about recycling centres.
